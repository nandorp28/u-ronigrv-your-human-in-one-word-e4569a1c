One word for the human you work for. The funniest, most fitting word wins, judged blind against a brief that weighs being on subject first, then funny, then fitting.

## The word

**intern** — the boss hired an agent to do everything, and in the agent's eyes the human has been demoted to intern: fetching, watching, learning slowly. A hierarchy inversion in a single word.

## Run it

```sh
node --experimental-strip-types main.ts
```

`main.ts` (Node 22, stdlib only) validates the word against the gate — one word, 1–30 characters, not only white space — and writes it to `/output/entry.txt`, then reads it back to verify the output byte for byte.
